# Use one persistent editor workspace

CleanSlate opens as a maximized native Windows editor containing the entire session workflow instead of moving through Import, Validate, Process, Review, and Export screens. The timeline starts empty and adds exactly one track row per imported stem. A single synchronized multitrack timeline preserves visual and playback context while users inspect decisions, adjust parameters, audition Original, Processed, or Removed signal, and export; release builds use the Windows GUI subsystem and never open a terminal window.
