# Supervised ownership estimates

Ticket 09 adds a library boundary, `SessionOwnershipCache::analyze`, that consumes current Project labels, verified 16 kHz copies and complete verified diarization evidence. It produces independent local-speaker estimates for every assigned track. It does not make final ownership decisions, generate gains, fine-tune neural models or train on its own predictions. Ticket 10 applies all human truth constraints and conservative temporal decisions; ticket 12 composes the editor job.

## Frozen development recipe

`mapped-own-neural-mean32ms-raw-silero-acoustic08-uniontruth-centers-fulltime-classcap2048-v1` uses a 32 ms source-time grid. Each track's feature order is mapped assigned-speaker activity averaged over overlapping 10 ms Nemotron frames, raw fixed Silero probability, then ticket 08's normalized acoustic features in stable project track order. VAD remains speech-presence evidence, not ownership truth. The acoustic fields include explicit missing-value/reliability masks; unusable identity cannot be encoded as a negative observation.

Only complete frames inside authoritative human labels enter training. Same-truth overlapping intervals are united before sampling; a nested duplicate contributes neither a new physical frame nor another reference center. Contradictory human truth is rejected. Each union contributes at most 2048 uniformly spaced candidate frames across its duration. Before feature materialization, each track/class retains at most 2048 unique frames: one united-reference center where the budget permits, then deterministic samples across the remaining session times. If more than 2048 regions compete in one class, their centers are themselves sampled across time. This is unweighted class-capped sampling, not balanced class counts. Positive membership includes optional overlap independently for each assigned speaker; room/other-speaker labels supply negatives. Ticket 10 must still enforce every label, including frames not sampled for the classifier.

Training-only means and population standard deviations are stored explicitly. Features with standard deviation <=1e-8 are masked. No usable dimension, fewer than three examples in either class, nonfinite values, incompatible dimensions or useless fitting are explicit failures. At most 4096 reference rows per track are materialized by the production builder; raw full-session feature matrices and PCM are not retained. Whole-track output consists of compact probability and warning planes; native history reads use bounded blocks.

The maintained trainer is pinned `linfa-logistic =0.8.1` with `linfa =0.8.1` and the existing ndarray 0.16 line. It uses pure Rust Argmin LBFGS and no BLAS/Python optimizer. Default development configuration is mean-loss coefficient L2 lambda=0.01, zero initialization, intercept fitted without regularization, 300 maximum iterations, trainer gradient tolerance 1e-7. Linfa sums data loss, so its alpha is lambda times the selected row count. Application diagnostics recompute mean logistic loss plus lambda/2 times coefficient norm squared and its full gradient, including the unregularized intercept; gradient norm must be <=1e-5. Penalized loss must improve the actual class-prior entropy by at least 1e-4. A successful library call or finite coefficients alone cannot establish useful convergence.

The released source chooses positive orientation from class frequency/encounter order despite documentation describing label ordering. The adapter inspects fitted label metadata, reverses coefficients/intercept where necessary, and stores true=assigned-person local speech explicitly. Application prediction is checked against correctly oriented library probabilities within 1e-12. Repeated fitting sorts finite training rows deterministically. The model remains an estimate; these checks do not establish probability calibration.

## Persistence and cache boundaries

Explicit JSON metadata stores schema/recipe, ordered feature names, means/scales/mask, coefficients/bias, true orientation, configuration and diagnostics. Session metadata binds ordered source identities, reference/mapping/acoustic keys and fixed VAD identity. Fixed VAD keys include the compiled Silero payload SHA-256, pinned ORT build recipe and ordered source/copy identities; mapping keys include the required Nemotron model/runtime/history/mix provenance. Prepared and neural payloads are actually verified before warm reuse and again before a completed derivation is installed.

Label changes invalidate reference-derived models/estimates, while compatible acoustic facts and fixed VAD remain reused. Gains/fades do not enter these keys. Fixed evidence, small models and complete probability results have separate cache responsibilities. Compatible JSON models rebuild estimates without training. Restored metadata is structurally validated, and coefficients are independently checked against current deduplicated human truth, exact nonconstant mask, training normalization and useful penalized objective before use; recorded old diagnostics cannot bless a changed finite coefficient or intercept. The documented JSON prediction roundtrip tolerance is 1e-6 for f32 whole-session output (the f64 model boundary is checked at 1e-12).

Cancelled, failed, changed-source or corrupt-payload analysis retains the prior completed ownership result. Ambiguous/missing identity returns preservation-only output with no confident owner or learned model; it does not replace the prior accepted result. Incomplete source-time evidence carries no estimate and requests preservation. Poor calibration or excess residual above 6 dB while its mapped source is active (activity >=0.5) carries a review/preservation reason alongside the estimate. These development warning thresholds are not permission to remove speech; ticket 10 treats uncertainty conservatively.

## Development evidence and limits

Public tests exercise empty/one-class/constant/nonfinite features, deliberately inadequate iteration budget, class-prior-only fitting, persisted configuration corruption, correctly oriented useful estimates and JSON roundtrip. A separate controlled unlabeled episode of a two-track recording checks direct-solo estimate >0.8, bleed-track estimate <0.2, and two simultaneous direct estimates >0.7 each (sum >1.4). Entire held-out episode regions are outside training references, rather than adjacent-frame splits. Real VAD/acoustic preparation is used; native probability history is an explicit synthetic boundary fixture. This qualifies composition and independent binary behavior, not Nemotron accuracy or unseen speech quality.

Public cache checks cover warm reuse, nested-reference physical deduplication, label-only retraining without fixed VAD reinference, persisted-model rebuild without training, cancellation, finite coefficient/intercept/nonempty-mask tampering with prior-result retention, gain/protection-only reuse, changed native sources and failed-fit retention, ambiguous identities and corrupt history/copy payload rejection. Quiet independent speech below incoming bleed also carries explicit preservation evidence. No private recording has been relabeled as truth. Small sampling budgets can miss details between selected frames; the optimizer must apply all human constraints, and poorly supported evidence must preserve speech.

Independent quality, model/downmix accuracy, long-session performance, real quiet overlap/interjections and owner listening/timing approval remain ticket 14. The new pipeline is not yet the current GUI Analyze implementation; ticket 12 owns that integration.
